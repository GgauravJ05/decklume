The journey

Five stops between Enter and paint

  1. Find the server DNS
  2. Open a connection TCP
  3. Make it private TLS
  4. Ask for the page HTTP
  5. Turn bytes into pixels Rendering

A page load is a chain of round trips.

Bandwidth matters for big files; for a first visit, waiting on round trips usually dominates.

Stop 1 · DNS

The name becomes an address

  1. Local caches

    The browser and the operating system check what they already know.

  2. Recursive resolver

    Usually your ISP or a public resolver does the lookup for you.

  3. Root and TLD

    They point the resolver to the servers responsible for the domain.

  4. Authoritative server

    It returns the IP address, which is cached for its TTL.

Stop 2 · TCP

Three messages, one round trip

The client can send its first data right after the ACK, so connection setup costs one round trip.

Measure it yourself

The browser already records every stop

const [nav] = performance.getEntriesByType("navigation");

const dns  = nav.domainLookupEnd - nav.domainLookupStart;
const tcp  = nav.connectEnd - nav.connectStart;
const tls  = nav.secureConnectionStart
  ? nav.connectEnd - nav.secureConnectionStart : 0;
const ttfb = nav.responseStart - nav.requestStart;
const load = nav.loadEventEnd - nav.startTime;
console.table({ dns, tcp, tls, ttfb, load });

Each press focuses one measurement. Run this in the console on any page.
