AI can write a whole presentation in seconds. Then you spend an hour fixing it: text spilling off slides, colours you can't read, every slide the same bullet list.

So I built Decklume, and today it's open source.

It's a free Claude Code skill that turns a topic, your notes or an existing PowerPoint into a presentation that looks designed, not generated.

What makes it different:

→ Story first. It drafts the outline with a one-line claim as every headline, and you approve it before any design happens.
→ You pick a style by seeing your own slides. It renders your real title and content slides in three different looks, side by side.
→ Design is code, not prompts. 13 themes and 26 tested layouts (matrices, roadmaps, pricing tiers, timelines, charts, code walkthroughs) on a fixed grid and type scale. The model writes the content; it never hand-places a text box.
→ Nothing ships until it passes QA. Every slide is rendered in a real browser and checked for overflow, overlapping text, contrast and type size. The 29-slide demo lecture passes in all 13 themes with 0 errors.

You get one HTML file with Magic Move transitions and a presenter view, plus a vector PDF with selectable text.

It's built for students, teachers, researchers and founders: anyone with a talk next week and no time to fight a slide editor.

Live demos of every theme: ggauravj05.github.io/decklume
Code (MIT): github.com/GgauravJ05/decklume

I'd love feedback, especially on which layouts or themes you'd want next.
