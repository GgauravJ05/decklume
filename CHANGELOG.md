# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-10-12

### Added
- `SKILL.md` workflow: brief → storyline approval → side-by-side style
  discovery → build → mandatory QA gate → delivery.
- Engine: fixed 1920×1080 stage, design tokens, 22 slide layouts, staggered
  entrances, step builds, Magic Move via View Transitions, SVG charts.
- Runtime: keyboard/touch/wheel navigation, deep links, overview, presenter
  window with notes and timer, blackout, grid overlay, in-browser editing.
- Ten themes: Folio, Nocturne, Grid, Campus, Atlas, Aurora, Volt, Ma, Bloom, Chalk.
- Scripts: `build`, `preview`, `qa`, `export` (vector PDF / PNG), `extract-pptx`,
  `deploy`.
- Claude Code plugin marketplace packaging.
- Example lecture, live demos, landing page, CI with tests and design QA.
