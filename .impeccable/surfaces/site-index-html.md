# Surface brief: decklume website

Scope: the public marketing + SEO site (home, 10 theme pages, 4 audience pages,
docs, comparison, 404), static HTML in `site/`, generated by
`scripts/build-site.mjs`. Visitor mode: Persuade (docs page leans Read inside the
same world).

Audience: students, teachers, researchers, founders, weighted equally; arriving
from search, GitHub and social. Action: install the plugin (copyable command),
then play a demo deck. Proof: real slides from the showcase lecture in all ten
themes, live demo decks, measured numbers (0.8 MB PDF, 17 tests, 10 themes pass
QA). Constraints: no fabricated testimonials or counts; fast on school laptops;
not busy, not childish, not AI-startup, not text-heavy.

Dynamic components (confirmed): playable deck in the hero, live theme switcher,
prompt-to-deck scroll story, QA inspector demo.

## Direction contract

THESIS: Decklume's site is a photographer's contact sheet of real slides: you
scan frames, a grease pencil circles the keeper, the circled frame plays. It
refuses the dark-gradient tool landing and the cream-serif editorial default.

OWN-WORLD: Silver-gelatin print paper ground (#F1EEE7), film-black sheets
(#0D0D0D) with sprocket rebates and edge numbers set in Martian Mono, Schibsted
Grotesk at heavy weight for headlines, grease-pencil red (#E4362B) and yellow
(#F2C230) marks hand-drawn (Reenie Beanie + SVG strokes). Chrome is achromatic;
colour only ever comes from the slides inside frames.

STORY: Visitors see real slides first, understand "Claude makes these, checked",
watch one play, swap its theme, see QA catch defects, then copy the install command.

FIRST VIEWPORT: Nav top row; headline "Pick the frame. Ship the deck." top-left
at ~92px; install command + demo button top-right; a full-width black contact
sheet (3 strips × 6 frames of real slides) filling the lower 60%, one frame
circled in red grease pencil and enlarged into the live, playable deck.

FORM: Contact Sheet, my rank #1 of 7 (Impeccable's pick, chosen by the user over
the roll's assignment). Seed key 04cf567b.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
