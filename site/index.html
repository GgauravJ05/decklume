Questions people ask

How do I make a presentation with Claude?

Install the Decklume skill in Claude Code, then describe the presentation you need, for example: “Make a 15-minute lecture on photosynthesis for first-year students.” Decklume agrees the outline with you, shows your slides in three styles, builds the deck and checks it with an automated design QA pass.

Is Decklume free?

Yes. Decklume is free and open source under the MIT license. It runs inside Claude Code.

Can Decklume convert my PowerPoint?

Yes. It reads .pptx files, including bullet levels, tables, images in groups, speaker notes and native chart data, and redesigns them as an animated HTML deck.

What do I get at the end?

A single self-contained HTML file that runs in any browser, with a presenter view. Export it as a vector PDF with selectable text, PNG images per slide, or deploy it to a live link.

What does the design QA check?

It renders every slide in a real browser and fails the deck on text overflowing its box, overlapping text, type below the minimum size, WCAG contrast failures, web fonts that did not load, leftover placeholder text, broken images and JavaScript errors.

Does it work outside Claude Code?

The skill is Markdown plus Node scripts, so any coding agent with file and shell access can follow it. The command-line tools also work on their own.
