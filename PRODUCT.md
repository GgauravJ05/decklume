# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated: static HTML/CSS + vanilla JS, generated by the repo's own Node
script (`scripts/build-site.mjs`), deployed to GitHub Pages from `site/`.
Chosen for crawlable server-rendered HTML, no build dependencies, and the
fastest possible Core Web Vitals, matching Decklume's own zero-dependency output.

## Users

Weighted equally (confirmed): students (school and university, making class
presentations, theses and project demos), teachers and lecturers, researchers,
and founders/makers (pitch decks, demo days). All use or are willing to use
Claude Code. The website visitor is evaluating whether to install a Claude Code
skill to make presentations.

## Product Purpose

Decklume is a free, open-source (MIT) Claude Code skill and plugin that turns a
topic, notes, a document or a PowerPoint into a designed, animated, single-file
HTML presentation. Success for the website: a visitor understands what it makes,
sees real output, and installs it (and stars the repo).

## Positioning

Decklume controls design with code rather than prompts: design tokens, 22 tested
layouts and complete themes, plus an automated design QA gate that renders every
slide in a real browser and fails the deck on overflow, overlap, contrast, type
size and font defects. It outlines the story first and shows the user's own
slides in three themes side by side before building. An original project by
GgauravJ05; it competes with other Claude slide skills such as frontend-slides.

## Operating Context

Visitors arrive from Google, GitHub search/topics, social posts and Claude
community links. They install via `/plugin marketplace add` + `/plugin install`
in Claude Code, or copy the skill folder. Decks are presented in a browser
(keyboard, presenter window), exported to PDF/PNG, or deployed to a URL.

## Capabilities and Constraints

- 10 themes: Folio, Nocturne, Grid, Campus, Atlas, Aurora, Volt, Ma, Bloom, Chalk.
- 22 layouts; Magic Move (View Transitions), step builds, SVG charts (bar, hbar,
  line, donut), presenter window (notes, timer, next slide), overview, in-browser
  editing, vector PDF and PNG export, PPTX import, Vercel deploy, design QA.
- Requires Claude Code; Node 18+; Playwright auto-installs to a cache for QA,
  previews and export. PowerPoint import is pure Node (no Python).
- Output is HTML (not .pptx); PDF export covers file-based needs.
- Repo is private until the user's planned launch; the site must work once public
  at https://ggauravj05.github.io/decklume/.

## Evidence on Hand

- Real example: 25-slide lecture "How Sleep Shapes Memory"
  (`examples/sleep-and-memory/`), live in all 10 themes (`site/demos/`).
- Measured: vector PDF of that deck is 0.8 MB with selectable text; PDF export
  takes ~3 s; 24 automated tests; every theme passes QA on the showcase deck.
- Absent and must not be fabricated: testimonials, user counts, star counts,
  download numbers, press, logos of organisations using it. A live GitHub star
  count may be shown only once the repo is public (fetched, never hardcoded).

## Product Principles

1. Show real output before making claims: live decks are the proof.
2. Honest numbers only: every figure on the site is measured or verifiable.
3. Equal welcome for students, teachers, researchers and founders.
4. Credit the work Decklume builds on.
5. Installing should take under a minute and be copy-paste simple.

## Accessibility & Inclusion

WCAG 2.2 AA for the site (contrast, keyboard access, reduced motion), matching
the AA contrast the product itself enforces on decks.
